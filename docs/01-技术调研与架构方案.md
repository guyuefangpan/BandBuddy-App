# 米环资源大全 App —— 技术调研与架构方案

> 版本 v1.0 ｜ 日期 2026-08-18 ｜ 目标：接入米坛社区(BandBBS) 的小米手环第三方资源大全手机 App

---

## 一、米坛社区接入可行性调研结论

### 1.1 米坛社区现状（实测）

| 项目 | 实测结果 |
|---|---|
| 站点 | https://www.bandbbs.cn（米坛社区 BandBBS） |
| 论坛引擎 | **XenForo 2.x**（`/threads/`、`/resources/` URL 结构 + 官方 JSON 错误格式确认） |
| 官方 API | ✅ **已启用**。`/api/threads`、`/api/resources`、`/api/users/me` 均返回标准 XenForo JSON 错误 |
| 认证方式 | API Key（请求头 `XF-Api-Key`），无 key 返回 `no_api_key_in_request` |
| 资源模块 | XenForo Resource Manager，资源列表页 `/resources/`，可按分类前缀过滤（如 `/resources/?prefix_id=52` 为手环6表盘） |
| 资源下载 | 资源详情页提供下载，通常要求登录后可见，部分资源需付费/权限 |
| 页面结构 | 列表页条目含：资源ID、分类标签、标题、描述、作者、图标(`/data/resource_icons/`) |

### 1.2 API Key 获取路径

XenForo 2.2+ 支持**用户自助生成 API Key**（后台开启后）：

1. 注册/登录米坛社区账号
2. 进入 **个人控制台 → API 访问 (API Access)**
3. 新建 API Key，选择所需权限范围（至少勾选 Resource Manager 读权限）
4. 复制 key，粘贴进本 App 的「设置 → 米坛 API Key」

> ⚠️ 若米坛管理员未开放自助生成，需在站内私信管理员申请 API Key。
> 本 App 内置 **HTML 解析兜底模式**：无 Key 时也能浏览资源列表/详情（下载需在站内完成），保证功能可用性。

### 1.3 合规与风控提醒

- 接入官方 API 符合 XenForo 生态的预期用法，数据获取合规；
- HTML 解析模式需控制请求频率（建议 ≥2s/次），避免对站点造成压力或被反爬策略限制；
- 资源版权归原作者所有，App 仅做聚合展示与跳转，不缓存/分发资源本体（下载走米坛站内），尊重社区规则。

## 二、产品定位与功能设计

### 2.1 产品定位

面向小米手环/小米手表玩家（"自己/小圈子"）的资源聚合工具：**一手逛资源，一手装表盘**。

### 2.2 功能矩阵（四大模块）

| 模块 | 功能点 | 说明 |
|---|---|---|
| **资源聚合浏览/搜索** | 按手环型号分类（手环5/6/7/8/9/10、Pro 系列）| 基于米坛分论坛/资源前缀映射 |
| | 关键词搜索 | 搜索资源标题/描述 |
| | 排序：最新/热门/评分 | 最新更新、下载量、评分排序 |
| | 资源列表卡片流 | 图标 + 标题 + 作者 + 版本 + 更新时间 |
| **资源下载** | 资源详情页 | 完整描述、版本历史、截图、评分 |
| | 一键下载 | 已配置 API Key → 走 API 下载；未配置 → 跳转站内页面 |
| | 下载链接解析 | 解析米坛资源下载地址（含登录态 Cookie 可选） |
| **多站聚合** | 内置聚合源 | 米坛(BandBBS) + GitHub 开源表盘仓库 + 轻腕(预留) |
| | 统一数据模型 | 各源转换为统一 Resource 模型，混合展示 |
| **本地收藏/管理** | 收藏夹 | 收藏的资源跨源统一管理 |
| | 下载历史 | 记录已下载文件，可重新打开/分享 |
| | 本地库检索 | 按型号/类型/来源筛选 |

### 2.3 页面结构

```
App
├── Tab1 首页（发现）
│   ├── 型号分类横向导航（手环5~10 / 手表系列）
│   └── 资源卡片瀑布流（最新/热门 切换）
├── Tab2 搜索
│   ├── 关键词搜索框 + 历史记录
│   └── 结果列表（按来源聚合）
├── Tab3 收藏
│   ├── 收藏列表（跨源）
│   └── 下载历史
├── Tab4 我的（设置）
│   ├── 米坛 API Key 配置（含申请指引）
│   ├── 数据源管理（启用/停用各聚合源）
│   ├── 关于/合规说明
│   └── 缓存清理
└── 资源详情页（从列表进入）
    ├── 大图/图标 + 标题 + 作者 + 分类标签
    ├── 描述、版本历史、评分
    ├── 「下载」按钮（API 直下 / 跳转站内）
    └── 「收藏」「分享」
```

## 三、技术架构

### 3.1 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 跨平台框架 | **Flutter 3.47 (Dart 3)** | 一套代码出 Android/iOS；UI 一致性好；国内生态成熟 |
| 状态管理 | **Provider (ChangeNotifier)** | 轻量、易维护，适合中小型应用 |
| 本地存储 | **sqflite (SQLite)** | 收藏/历史/本地库，无需额外服务 |
| 网络 | **dio + cookie_jar** | 拦截器统一处理 API Key 头；Cookie 持久化支持登录态 |
| HTML 兜底解析 | **html 包**（Dart） | 解析 XenForo 列表/详情页 |
| 打包 | Android APK (Gradle) | 优先交付 Android 安装包；iOS 需 macOS 环境后续支持 |

### 3.2 分层架构

```
┌─────────────────────────────────────────────────┐
│                    UI 层 (Flutter)               │
│  首页发现 / 搜索 / 收藏 / 我的 / 资源详情           │
├─────────────────────────────────────────────────┤
│                业务层 (Providers)                 │
│  资源流聚合器(合并多源) / 搜索 / 收藏 / 下载管理器   │
├─────────────────────────────────────────────────┤
│               数据接入层 (Adapters)               │
│  ┌───────────┐ ┌──────────┐ ┌────────────────┐  │
│  │BandBBSApi │ │ HTML 兜底 │ │ GitHub 聚合源   │  │
│  │(XenForoAPI)│ │(无Key时)  │ │(开源表盘仓库)   │  │
│  └───────────┘ └──────────┘ └────────────────┘  │
├─────────────────────────────────────────────────┤
│        基础设施: dio / cookie_jar / sqflite       │
└─────────────────────────────────────────────────┘
```

### 3.3 统一数据模型

```dart
class BandResource {
  final String source;        // 来源: bandbbs / github / ...
  final String sourceId;      // 源内唯一ID（如米坛资源ID）
  final String title;         // 标题
  final String category;      // 分类标签(表盘/小程序/固件/工具)
  final String deviceModel;   // 适配型号(手环8/手环9...)
  final String author;        // 作者
  final String version;       // 版本
  final String coverUrl;      // 封面图URL
  final String detailUrl;     // 详情页URL
  final String downloadUrl;   // 下载URL(可为空)
  final int rating;           // 评分(0-5)
  final int downloads;        // 下载数
  final DateTime updatedAt;   // 更新时间
  final String description;   // 描述(详情页拉取)
}
```

### 3.4 米坛 API 调用设计

```
请求头: XF-Api-Key: <user_key>   (dio 拦截器统一注入)

资源列表:  GET /api/resources?page=1&order=last_update
资源详情:  GET /api/resources/{id}
资源搜索:  GET /api/resources?q=关键字
用户信息:  GET /api/users/me            → 校验 Key 有效性
```

兜底解析（无 Key）：
```
资源列表:  GET /resources/?prefix_id={分类}   → 正则提取条目
资源详情:  GET /resources/{id}/               → 提取描述/版本/下载链接
```

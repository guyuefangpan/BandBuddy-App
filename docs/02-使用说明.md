# 米环资源大全 App —— 使用说明

> 聚合米坛社区(BandBBS)等来源的小米手环第三方资源（表盘 / 小程序 / 固件 / 工具）

## 一、安装

1. 将 `bandbuddy_app-release.apk`（或 debug 版）传到手机（微信/QQ/数据线均可）
2. 点击安装。若提示"未知来源应用"，请在系统设置中允许该来源
3. Android 7.0+ 直接安装；Android 13+ 部分机型需关闭"安装外部来源应用"限制

## 二、快速开始（无需配置）

安装后打开即可使用：

| 功能 | 入口 | 说明 |
|---|---|---|
| 浏览资源 | 发现页 | 按手环型号分类（手环4~10、Pro系列）+ 类型标签筛选 + 推荐/最新排序 |
| 搜索 | 发现页右上角 🔍 | 关键词 + 型号 + 类型筛选 |
| 下载 | 详情页「下载资源」 | 登录后 App 内直接下载（系统保存框选择位置）；GitHub 直连资源同样 App 内下载 |

> 默认使用**页面浏览模式**，无需任何配置即可浏览全部型号资源。

## 三、登录米坛账号（可选，推荐）

登录通过**应用内网页**完成，登录后可在 **App 内直接下载资源**（无需跳转浏览器）：

1. 打开 App → **我的 → 登录米坛账号** → 应用内打开米坛登录网页
2. 在网页中登录米坛账号（支持注册）；密码只交给米坛官方页面，本应用不接触
3. 登录完成后点「已完成登录」，软件自动抓取会话；若本机已登录会自动识别同步
4. 之后任意资源详情 → 下载资源 → App 内直接下载，完成时弹系统保存框选择保存位置

> 会话仅保存在本机，用于应用内浏览与下载；付费/权限受限资源下载会提示失败。

## 四、数据源管理（我的 → 数据源）

| 开关 | 说明 |
|---|---|
| 米坛社区 | 米坛资源源（页面浏览模式） |
| GitHub 开源仓库 | 聚合开源表盘/工具仓库的 Releases |
| 页面浏览模式 | 解析米坛页面浏览资源（默认开启） |

GitHub 仓库列表可编辑：每行一个 `owner/repo`。

> **v1.0.1 修复**：型号分类改用米坛官方 Resource Category 结构
> （`/resources/categories/{id}/`，分类 ID 为 2026-08-19 实测值），
> 并适配米坛新版 `structItem` 列表模板。现在切换型号、上滑加载更多均正常。
> **v1.0.3 变更**：登录改为**系统浏览器授权**（应用内 WebView 在部分机型被
> 米坛拦截，已移除）；下载米坛资源时自动用浏览器打开，登录态由浏览器保持。

## 五、常见问题

**Q：列表加载慢 / 加载失败？**
A：米坛页面兜底模式请保持合理刷新频率；GitHub 源在国内网络可能不稳定，可在数据源中关闭。

**Q：为什么下载用浏览器打开而不是 App 内直下？**
A：米坛资源下载要求登录态（含权限校验），无法绕过站内流程直接取文件。用浏览器打开可复用浏览器中的登录状态，登录后点下载即可；GitHub 等直连资源会在 App 内直接下载并记录。

**Q：下载历史存在哪里？**
A：「收藏 → 下载历史」。App 内直连下载的文件存于 App 文档目录 `downloads/` 下；米坛站内下载的文件由站内流程管理。

**Q：浏览器登录后回到 App，还需要做什么？**
A：什么都不用做，保持浏览器登录即可。之后点任意米坛资源的「下载」，浏览器会自动打开资源页（已登录）直接下载。

## 六、合规提示

- 数据来自米坛社区**公开页面**（登录态仅用于浏览本应可见的内容），符合 XenForo 生态规范；
- 资源版权归原作者所有，本应用仅聚合展示与跳转，**不缓存/分发资源本体**；
- 请合理控制请求频率（页面模式建议 ≥2 秒/次），避免对站点造成压力。

## 七、二次开发

源码工程位于 `bandbuddy_app/`（Flutter 3.47 / Dart 3.13）：

```
flutter pub get
flutter run          # 连接设备或模拟器运行
flutter build apk --release   # 打正式包
```

主要目录：
- `lib/core/` 配置与统一数据模型
- `lib/data/adapters/` 数据源适配器（BandBBS API / HTML 兜底 / GitHub）
- `lib/providers/` 状态管理
- `lib/pages/` 四大模块页面
